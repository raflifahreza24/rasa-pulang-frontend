# Rasa Pulang — Frontend

A responsive website for Rasa Pulang, a fictional Indonesian snack and souvenir shop based in Sidoarjo, East Java.

This independent portfolio project demonstrates a public product catalog and an administrative dashboard built with React and Vite.

## Project Scope

This repository contains the frontend version using mock data and simulated interactions. It does not connect to a backend or database.

Rasa Pulang and its business information are fictional and used for portfolio purposes.

## Features

### Public Website

- Homepage.
- Product catalog with search, category filters, sorting, and pagination.
- Product detail pages.
- About page.
- Contact and location page.

### Admin Dashboard

- Demo login for owner and staff.
- Catalog overview.
- Category management.
- Product listing, creation, and editing.
- Product trash and restoration.
- Website content management.
- Store settings.
- Staff account management.
- Personal profile.

## Tech Stack

- React.
- Vite.
- CSS — Inter typography with a cream, brown, and orange color palette.

## Demo Limitations

- Authentication and role restrictions are frontend simulations.
- Data changes may reset when the page is refreshed.
- Image selection provides local previews and does not upload files to a server.
- WhatsApp and social links require valid contact configuration.
- No shopping cart, checkout, online payment, or automatic inventory tracking.

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
